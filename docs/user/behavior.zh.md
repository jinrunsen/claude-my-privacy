# 替换行为与覆盖边界

[English](behavior.md) | 中文

插件让模型在支持的文本中使用化名，让工具尽量使用真实路径和账号。它采用指定词替换策略，不默认拦截操作；Claude Code 原生权限及其他插件仍可拒绝工具调用。

<a id="输入到执行的流程"></a>

## 输入到执行的流程

下表区分模型上下文、实际工具参数和最终文件。启用的词表来自[私有配置](configuration.zh.md)。

| 内容或阶段 | 插件行为 |
| --- | --- |
| 用户提交的文本、支持的提示上下文、附件文本和 skill（技能）提示 | 原文替换为化名 |
| Bash 命令及普通工具的字符串参数值 | 化名恢复为原文 |
| Write 内容、Edit 查找和替换文本 | 执行前尝试恢复，再交给原生工具处理 |
| 工具返回的支持文本 | 再次替换为化名 |
| Agent、Task、Skill 参数 | 保持化名，供后续模型使用 |
| WebFetch | URL 按执行参数恢复；`prompt` 保持化名 |
| 支持的助手回复显示文本 | 仅为显示尝试恢复原文 |
| 追加会话中的支持文本 | 原文替换为化名；显示恢复不改写这些文本 |

无论显示的是原文还是剩余化名，都不能据此断定文件或网络请求使用了哪个值。工具返回文本已被替换，也不能作为本机原始文件内容的逐字证据。

工具参数对象键及 `tool`、`tool_use_id`、`agentId` 等路由字段保持不变。未知 MCP 工具的字符串参数默认恢复；插件无法识别该工具内部是否再次调用模型。

<a id="assistant-reply-display"></a>

## 助手回复显示

显示恢复仅适用于宿主通过 `AssistantMessage` 组件呈现的助手文本。用户消息和工具显示不在此次恢复范围内。每个文本块独立处理，因此跨块拆分的化名可能保留。恢复失败时，宿主显示原有文本及其中的化名。

恢复后的显示文本不会写回已存储的会话文本或模型上下文。这些内容仍受下述尽力替换策略及覆盖限制约束。普通 `--print` 输出不在显示恢复范围内，会保留化名。流式输出、复制或导出以及其他客户端均无通用恢复保证。

<a id="shell-与文件写入"></a>

## Shell 与文件写入

Bash 对整条命令做字面恢复，不解析、重新引用或拼装 Shell。因此 `;`、`&&`、管道、循环、多行脚本和 heredoc 没有专门的放行要求。恢复范围也包括命令内嵌的脚本和账号字符串。

这不等于任意映射都能保持命令含义：映射值中的 Shell 特殊字符可能改变执行结果。只有出现在命令文本中的化名才会被恢复；命令运行后从环境变量、文件或远端读取的内容，不会被插件在执行环境中递归改写。

Write 和 Edit 的文本参数会在执行前恢复，Bash 内嵌的文件写入文本也会随命令恢复。插件不会扫描磁盘并自动修复已经写入的化名。原生工具报错也不保证没有发生写入。

<a id="路径域名与账号"></a>

## 路径、域名与账号

对普通工具明确提供的 `file_path`、`path`、`notebook_path`，若传入的化名路径已经存在，插件优先保留该路径；否则尝试恢复。存在的路径可能是软链接，也可能是独立文件，插件不会自动判断使用者的意图。

Bash 没有上述存在性优先逻辑：命令中的化名路径按整条命令恢复。插件不创建软链接，也不依赖软链接才能工作。

域名和账号按字符串恢复，没有域名白名单、DNS 校验或账号真实性判断。例如，示例化名 `harborwave.example` 作为工具参数时会恢复成 `cedarbyte.example`。执行所需的原文会到达目标程序或服务，这是恢复真实账号和网络目标的结果。

切换化名后，配置只认识新词表；旧会话中的旧化名不会自动迁移。重新读取原始来源以获得新化名上下文，并检查实际目标后再执行有副作用的操作。

<a id="失败与覆盖限制"></a>

## 失败与覆盖限制

替换异常时尽量放行原内容并记录结构元数据。每次工具调用只尝试执行一次，结果替换失败不会触发重试。缺失或非法配置也会原样通过，详见[配置状态](configuration.zh.md#文件位置与加载)。

保护不覆盖所有输入和存储：

- 未配置的信息保持原样；插件没有通用邮箱、手机号、证件号识别功能。
- 图片、PDF、音频和其他不支持的媒体原样通过，不进行 OCR。
- 签名思考、固定的工具调用历史、系统快照、原始队列和文件快照可能保留原文。
- 插件不重写全部历史日志，不撤回已发送数据；旧 `<PII_...>` 占位符也不会自动恢复。
- 本机 Claude Code 和工具仍可读取真实文件；其他插件的输入、网络行为和日志不能由本插件全面保证。

因此，本插件只能减少指定词在支持文本中的暴露，**不能保证全部请求、显示内容或日志都已脱敏**。离线验证检查到的范围见[验证说明](../../verification/README.zh.md)。
